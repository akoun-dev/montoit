## Introduction

L'API NeoFace V2 est une solution de vérification d'identité par reconnaissance faciale. Elle permet de :

- Capturer et stocker des documents d'identité
- Effectuer une vérification faciale avec détection de vivacité (liveness)
- Comparer le visage d'un selfie avec celui du document d'identité
- Consulter le statut de vérification

**URL de base :** `https://neoface.aineo.ai/api/v2`

**Version :** 2.0

---

## Authentification

L'API utilise une authentification par **Bearer Token**.

### Format de l'en-tête

```http
Authorization: Bearer <votre_token>
```

### Obtention d'un token

Les tokens sont fournis par l'équipe NeoFace lors de la création de votre projet. Chaque token est :

- Unique (64 caractères alphanumériques)
- Lié à un projet et un client spécifiques
- Peut avoir une date d'expiration optionnelle
- Peut être révoqué à tout moment

### Méthodes d'authentification alternatives

Pour certains endpoints, le token peut également être envoyé dans le corps de la requête :

```json
{
  "token": "votre_token_ici"
}
```

## Endpoints

### 1. Document Capture

Télécharge et enregistre un document d'identité pour vérification.

**Endpoint :** `POST /api/v2/document_capture`

**Authentification :** Bearer Token (obligatoire)

**Limite de débit :** 10 requêtes par minute par IP

#### Paramètres de la requête

| Paramètre | Type | Obligatoire | Description |
|-----------|------|-------------|-------------|
| `token` | string | Oui* | Token d'authentification (*si non fourni dans l'en-tête) |
| `doc_file` | file/base64 | Oui | Image du recto du document (JPG ou PNG) |
| `doc_file_verso` | file/base64 | Non | Image du verso du document (JPG ou PNG). Pour les CNI, permet d'extraire le NNI, la profession, la date et le lieu d'emission. |

#### Format 1 : Multipart Form-Data

```http
POST /api/v2/document_capture HTTP/1.1
Host: neoface.aineo.ai
Authorization: Bearer votre_token
Content-Type: multipart/form-data

--boundary
Content-Disposition: form-data; name="doc_file"; filename="document_recto.jpg"
Content-Type: image/jpeg

[contenu binaire du recto]
--boundary
Content-Disposition: form-data; name="doc_file_verso"; filename="document_verso.jpg"
Content-Type: image/jpeg

[contenu binaire du verso - optionnel]
--boundary--
```

#### Format 2 : JSON avec Base64

```http
POST /api/v2/document_capture HTTP/1.1
Host: neoface.aineo.ai
Authorization: Bearer votre_token
Content-Type: application/json

{
  "doc_file": {
    "name": "document_recto.jpg",
    "data": "base64_encoded_image_data",
    "mime_type": "image/jpeg"
  },
  "doc_file_verso": {
    "name": "document_verso.jpg",
    "data": "base64_encoded_image_data",
    "mime_type": "image/jpeg"
  }
}
```

> **Note :** Le champ `doc_file_verso` est optionnel dans les deux formats.

#### Réponse succès (201 Created)

**Sans OCR :**

```json
{
  "document_id": "doc-ABC123XYZ789",
  "url": "https://neoface.aineo.ai/api/selfie_facematch/doc-ABC123XYZ789",
  "success": true,
  "ocr": false,
  "type_doc": "",
  "nom": "",
  "prenom": "",
  "date_naissance": "",
  "sexe": "",
  "taille": "",
  "nationalite": "",
  "date_expiration": "",
  "numero_document": ""
}
```

**Avec OCR (recto uniquement) :**

```json
{
  "document_id": "doc-ABC123XYZ789",
  "url": "https://neoface.aineo.ai/api/selfie_facematch/doc-ABC123XYZ789",
  "success": true,
  "ocr": true,
  "type_doc": "Passeport",
  "nom": "DUPONT",
  "prenom": "Jean",
  "date_naissance": "15/03/1990",
  "sexe": "M",
  "taille": "1,78m",
  "nationalite": "Française",
  "date_expiration": "01/01/2030",
  "numero_document": "123456789012"
}
```

**Avec OCR (recto + verso CNI) :**

```json
{
  "document_id": "doc-ABC123XYZ789",
  "url": "https://neoface.aineo.ai/api/selfie_facematch/doc-ABC123XYZ789",
  "success": true,
  "ocr": true,
  "type_doc": "CNI",
  "nom": "DUPONT",
  "prenom": "Jean",
  "date_naissance": "15/03/1990",
  "sexe": "M",
  "taille": "1,78m",
  "nationalite": "Française",
  "date_expiration": "01/01/2030",
  "numero_document": "C123456789",
  "verso": {
    "nni": "1900312345678",
    "profession": "Ingenieur",
    "date_emission": "01/06/2020",
    "lieu_emission": "Dakar"
  }
}
```

> **Note :** Le champ `verso` n'apparait dans la reponse que si le document est detecte comme une CNI (Carte Nationale d'Identite) et que le fichier `doc_file_verso` a ete envoye.

#### Champs de la reponse

| Champ | Type | Description |
|-------|------|-------------|
| `document_id` | string | Identifiant unique du document (format: `doc-XXXXXXXXXXXX`) |
| `url` | string | URL de redirection pour la capture du selfie |
| `success` | boolean | Indicateur de succes de l'operation |
| `ocr` | boolean | `true` si l'extraction OCR a reussi |
| `type_doc` | string | Type de document detecte (CNI, Passeport, Permis, etc.) |
| `nom` | string | Nom de famille extrait du document |
| `prenom` | string | Prenom(s) extrait(s) du document |
| `date_naissance` | string | Date de naissance (format JJ/MM/AAAA) |
| `sexe` | string | Sexe (M ou F) |
| `taille` | string | Taille (ex: 1,78m) |
| `nationalite` | string | Nationalite |
| `date_expiration` | string | Date d'expiration du document |
| `numero_document` | string | Numero du document (CNI, passeport, etc.) |
| `verso` | object | Informations extraites du verso (CNI uniquement, optionnel) |
| `verso.nni` | string | Numero National d'Identite (precede par "NNI" sur le document) |
| `verso.profession` | string | Profession |
| `verso.date_emission` | string | Date d'emission du document |
| `verso.lieu_emission` | string | Lieu d'emission du document |

#### Réponses d'erreur

**400 Bad Request** - Paramètres invalides
```json
{
  "error": "Le fichier document est requis"
}
```

**401 Unauthorized** - Token invalide ou expiré
```json
{
  "error": "Token invalide ou expiré"
}
```

**429 Too Many Requests** - Limite de débit dépassée
```json
{
  "error": "Trop de requêtes. Veuillez réessayer plus tard."
}
```

### 2. Selfie Face Match

Interface web pour la capture du selfie avec détection de vivacité et correspondance faciale.

**Endpoint GET :** `GET /api/selfie_facematch/<document_id>`

**Endpoint POST :** `POST /api/selfie_facematch/<document_id>`

**Authentification :** Aucune (interface publique avec protection CSRF)

#### GET - Affichage de l'interface

Retourne une page HTML interactive avec :

- Accès à la caméra via WebRTC
- Détection faciale en temps réel (MediaPipe Face Mesh)
- Guide visuel (ovale de positionnement)
- Détection de vivacité (clignement des yeux requis)
- Instructions audio
- Capture automatique après validation

**Paramètre URL :**

| Paramètre | Type | Description |
|-----------|------|-------------|
| `document_id` | string | Identifiant du document retourné par `/document_capture` |

**Exemple :**
```
GET /api/selfie_facematch/doc-ABC123XYZ789
```

#### POST - Soumission du selfie

Soumet l'image du selfie capturé pour la comparaison faciale.

**Paramètres :**

| Paramètre | Type | Obligatoire | Description |
|-----------|------|-------------|-------------|
| `selfie_file` | file | Oui | Image du selfie capturé |
| `csrfmiddlewaretoken` | string | Oui | Token CSRF Django |

#### Réponse succès - Correspondance validée

```json
{
  "success": true,
  "redirect": "/api/success",
  "score": 0.95
}
```

#### Réponse succès - Correspondance échouée

```json
{
  "success": false,
  "redirect": "/api/error_404",
  "score": 0.45
}
```

| Champ | Type | Description |
|-------|------|-------------|
| `success` | boolean | `true` si le score >= seuil de validation |
| `redirect` | string | URL de redirection |
| `score` | float | Score de correspondance faciale (0.0 à 1.0) |

#### Réponse erreur

```json
{
  "success": false,
  "error": "Description de l'erreur"
}
```

### 3. Match Verify

Vérifie le statut de la correspondance faciale pour un document donné. Utilisé pour le polling asynchrone.

**Endpoint :** `POST /api/v2/match_verify`

**Authentification :** Bearer Token (obligatoire)

**Limite de débit :** 30 requêtes par minute par IP

#### Paramètres de la requête

```json
{
  "token": "votre_token",
  "document_id": "doc-ABC123XYZ789"
}
```

| Paramètre | Type | Obligatoire | Description |
|-----------|------|-------------|-------------|
| `token` | string | Oui* | Token d'authentification (*si non fourni dans l'en-tête) |
| `document_id` | string | Oui | Identifiant du document à vérifier |

#### Réponse - En attente (201 Created)

Le selfie n'a pas encore été soumis.

```json
{
  "status": "waiting",
  "message": "Matching en attente",
  "document_id": "doc-ABC123XYZ789"
}
```

#### Réponse - Vérifié avec succès (200 OK)

La correspondance faciale a réussi.

```json
{
  "status": "verified",
  "message": "Visage correspond",
  "document_id": "doc-ABC123XYZ789",
  "matching_score": 0.95,
  "verified_at": "2025-10-29T12:34:56Z"
}
```

#### Réponse - Vérification échouée (400 Bad Request)

La correspondance faciale a échoué.

```json
{
  "status": "failed",
  "message": "Visage ne correspond pas",
  "document_id": "doc-ABC123XYZ789",
  "matching_score": 0.45,
  "verified_at": "2025-10-29T12:34:56Z"
}
```

| Champ | Type | Description |
|-------|------|-------------|
| `status` | string | `waiting`, `verified`, ou `failed` |
| `message` | string | Message descriptif du statut |
| `document_id` | string | Identifiant du document |
| `matching_score` | float | Score de correspondance (présent si vérifié) |
| `verified_at` | datetime | Date/heure de la vérification (ISO 8601) |

#### Réponses d'erreur

**401 Unauthorized**
```json
{
  "error": "Token invalide"
}
```

**404 Not Found**
```json
{
  "error": "Document non trouvé"
}
```

## Limitations et quotas

### Limites de débit (Rate Limiting)

| Endpoint | Limite | Fenêtre |
|----------|--------|---------|
| `/api/v2/document_capture` | 10 requêtes | 1 minute |
| `/api/v2/match_verify` | 30 requêtes | 1 minute |

### Contraintes sur les fichiers

| Contrainte | Valeur |
|------------|--------|
| Taille maximale | 10 Mo |
| Formats acceptés | JPG, JPEG, PNG |
| Dimensions maximales | 8000 x 8000 pixels |

### Validation des fichiers

- Vérification de l'extension du fichier
- Vérification du type MIME réel (magic bytes)
- Validation de l'intégrité de l'image
- Protection contre les fichiers corrompus

---

## Sécurité

### Mesures de sécurité implémentées

1. **Authentification par token**
   - Tokens uniques de 64 caractères
   - Support des dates d'expiration
   - Révocation possible à tout moment

2. **Validation des fichiers**
   - Vérification du type MIME réel
   - Limite de taille
   - Sanitization des noms de fichiers
   - Protection contre les path traversal

3. **Protection CSRF**
   - Token CSRF requis pour les soumissions web

4. **Rate Limiting**
   - Limitation par IP
   - Cache distribué (Redis en production)

5. **Logging des appels API**
   - Journalisation complète
   - Masquage des données sensibles

6. **HTTPS** (Production)
   - SSL/TLS obligatoire
   - HSTS activé
   - Cookies sécurisés

### Recommandations

- Ne jamais exposer votre token dans le code client
- Utiliser HTTPS pour toutes les communications
- Implémenter une gestion des erreurs robuste
- Stocker les tokens de manière sécurisée (variables d'environnement)

### Étapes détaillées

1. **Upload du document**
   - Envoyez le document d'identité via `POST /api/v2/document_capture`
   - Récupérez le `document_id` et l'`url` de retour

2. **Redirection utilisateur**
   - Redirigez l'utilisateur vers l'URL fournie
   - L'interface de capture s'affiche automatiquement

3. **Capture du selfie**
   - L'utilisateur autorise l'accès à la caméra
   - Le système guide l'utilisateur (positionnement, clignement)
   - Le selfie est capturé automatiquement après validation

4. **Vérification**
   - Le système compare le selfie au document
   - Le résultat est affiché à l'utilisateur

5. **Récupération du statut**
   - Utilisez `POST /api/v2/match_verify` pour obtenir le résultat
   - Polling recommandé toutes les 2-5 secondes

## Exemples d'intégration

### Python

```python
import requests
import base64

API_BASE = "https://neoface.aineo.ai/api/v2"
TOKEN = "votre_token_ici"

# 1. Upload du document (recto + verso optionnel)
def upload_document(file_path, file_path_verso=None):
    headers = {
        "Authorization": f"Bearer {TOKEN}"
    }

    files = {"doc_file": open(file_path, "rb")}
    if file_path_verso:
        files["doc_file_verso"] = open(file_path_verso, "rb")

    response = requests.post(
        f"{API_BASE}/document_capture",
        headers=headers,
        files=files
    )

    # Fermer les fichiers
    for f in files.values():
        f.close()

    if response.status_code == 201:
        data = response.json()
        return data
    else:
        raise Exception(f"Erreur: {response.json()}")

# 2. Vérification du statut
def check_verification_status(document_id):
    headers = {
        "Authorization": f"Bearer {TOKEN}",
        "Content-Type": "application/json"
    }

    payload = {
        "document_id": document_id
    }

    response = requests.post(
        f"{API_BASE}/match_verify",
        headers=headers,
        json=payload
    )

    return response.json()

# Exemple d'utilisation
if __name__ == "__main__":
    # Upload (recto + verso pour CNI)
    result = upload_document("carte_identite_recto.jpg", "carte_identite_verso.jpg")
    doc_id = result["document_id"]
    print(f"Document ID: {doc_id}")
    print(f"URL de redirection: {result['url']}")
    print(f"OCR: {result.get('ocr')}")
    print(f"Nom: {result.get('nom')}, Prenom: {result.get('prenom')}")
    if "verso" in result:
        print(f"NNI: {result['verso'].get('nni')}")
        print(f"Profession: {result['verso'].get('profession')}")

    # Polling du statut
    import time
    while True:
        status = check_verification_status(doc_id)
        print(f"Statut: {status}")

        if status.get("status") in ["verified", "failed"]:
            break

        time.sleep(3)
```

### JavaScript (Node.js)

```javascript
const axios = require('axios');
const FormData = require('form-data');
const fs = require('fs');

const API_BASE = 'https://neoface.aineo.ai/api/v2';
const TOKEN = 'votre_token_ici';

// 1. Upload du document
async function uploadDocument(filePath) {
    const form = new FormData();
    form.append('doc_file', fs.createReadStream(filePath));

    const response = await axios.post(
        `${API_BASE}/document_capture`,
        form,
        {
            headers: {
                'Authorization': `Bearer ${TOKEN}`,
                ...form.getHeaders()
            }
        }
    );

    return response.data;
}

// 2. Vérification du statut
async function checkVerificationStatus(documentId) {
    const response = await axios.post(
        `${API_BASE}/match_verify`,
        { document_id: documentId },
        {
            headers: {
                'Authorization': `Bearer ${TOKEN}`,
                'Content-Type': 'application/json'
            }
        }
    );

    return response.data;
}

// Exemple d'utilisation
async function main() {
    try {
        // Upload
        const { document_id, url } = await uploadDocument('carte_identite.jpg');
        console.log(`Document ID: ${document_id}`);
        console.log(`URL de redirection: ${url}`);

        // Polling du statut
        const poll = async () => {
            const status = await checkVerificationStatus(document_id);
            console.log('Statut:', status);

            if (status.status === 'waiting') {
                setTimeout(poll, 3000);
            }
        };

        poll();
    } catch (error) {
        console.error('Erreur:', error.response?.data || error.message);
    }
}

main();
```

### PHP

```php
<?php

$API_BASE = 'https://neoface.aineo.ai/api/v2';
$TOKEN = 'votre_token_ici';

// 1. Upload du document
function uploadDocument($filePath) {
    global $API_BASE, $TOKEN;

    $curl = curl_init();

    $postFields = [
        'doc_file' => new CURLFile($filePath)
    ];

    curl_setopt_array($curl, [
        CURLOPT_URL => "$API_BASE/document_capture",
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_POST => true,
        CURLOPT_POSTFIELDS => $postFields,
        CURLOPT_HTTPHEADER => [
            "Authorization: Bearer $TOKEN"
        ]
    ]);

    $response = curl_exec($curl);
    curl_close($curl);

    return json_decode($response, true);
}

// 2. Vérification du statut
function checkVerificationStatus($documentId) {
    global $API_BASE, $TOKEN;

    $curl = curl_init();

    $payload = json_encode(['document_id' => $documentId]);

    curl_setopt_array($curl, [
        CURLOPT_URL => "$API_BASE/match_verify",
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_POST => true,
        CURLOPT_POSTFIELDS => $payload,
        CURLOPT_HTTPHEADER => [
            "Authorization: Bearer $TOKEN",
            "Content-Type: application/json"
        ]
    ]);

    $response = curl_exec($curl);
    curl_close($curl);

    return json_decode($response, true);
}

// Exemple d'utilisation
$result = uploadDocument('/chemin/vers/document.jpg');
echo "Document ID: " . $result['document_id'] . "\n";
echo "URL: " . $result['url'] . "\n";

// Polling
do {
    sleep(3);
    $status = checkVerificationStatus($result['document_id']);
    echo "Statut: " . $status['status'] . "\n";
} while ($status['status'] === 'waiting');

?>
```
