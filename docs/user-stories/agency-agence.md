## Gestion de l'Équipe

| ID       | User Story                                                                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| US-A-001 | En tant qu'agence, je veux gérer plusieurs agents au sein de mon équipe afin d'organiser l'activité commerciale                                         |
| US-A-002 | En tant qu'agence, je veux assigner des biens à des agents spécifiques afin de clarifier les responsabilités                                            |
| US-A-003 | En tant qu'agence, je wants suivre les commissions de chaque agent afin de calculer leurs rémunérations                                                 |
| US-A-004 | En tant qu'agence, je wants consulter les analytics de performance par agent afin d'identifier les meilleurs éléments                                   |

| US-A-006 | En tant qu'agence, je wants consulter les statistiques d'activité de l'équipe (nombre de visites, de baux signés) afin d'évaluer la performance globale |
