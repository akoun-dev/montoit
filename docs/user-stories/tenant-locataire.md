# User Stories - Locataire (Tenant)

## Recherche et Découverte de Biens

| ID       | User Story                                                                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| US-T-001 | En tant que locataire, je veux rechercher des biens par ville ou code postal afin de trouver un logement dans la zone géographique souhaitée                    |
| US-T-002 | En tant que locataire, je veux filtrer les résultats par type de bien (studio, T1, T2, maison) afin de trouver le type de logement qui correspond à mes besoins |
| US-T-003 | En tant que locataire, je veux filtrer les résultats par budget (loyer maximum) afin de ne voir que les logements que je peux me permettre                      |
| US-T-004 | En tant que locataire, je veux voir des photos détaillées des biens afin d'avoir un aperçu réel du logement                                                     |
| US-T-005 | En tant que locataire, je veux voir les équipements et commodités du bien afin de vérifier qu'il répond à mes critères                                          |
| US-T-006 | En tant que locataire, je veux consulter l'adresse exacte du bien afin d'évaluer sa localisation                                                                |
| US-T-007 | En tant que locataire, je veux ajouter des biens à mes favoris afin de les retrouver facilement plus tard                                                       |
| US-T-008 | En tant que locataire, je veux recevoir des notifications pour les nouveaux biens correspondant à mes critères afin de ne pas manquer d'opportunités            |
